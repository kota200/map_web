# Risk Register

| ID | Risk | Severity | Current evidence | Mitigation / gate |
|---|---|---:|---|---|
| R-01 | Memory64/pthreads are unavailable or unstable in some browsers | High | Packaged Kallisto requires Memory64 and cross-origin isolation | Runtime compile check plus capability gate; keep unsupported browsers disabled |
| R-02 | HISAT2 index exceeds browser memory/storage | Critical | W4 total-package preflight rejects impossible reservations; only the 4,203,807-byte synthetic package is tested | W6 representative multi-GiB benchmark; retain desktop recommendation |
| R-03 | Full-size index/FASTQ/SAM copies exhaust JS or Wasm memory | Critical | W3 selected WORKERFS + OPFS and proved zero full-size application transfers for a 64 MiB artifact and tiny SAM | Retain descriptor-only handoff; W6 multi-GiB peak-memory measurement |
| R-04 | Cross-origin index CDN breaks COEP/CORP/CORS | High | W4 passes only with same-origin fixture URLs; production origin is unconfigured | Validate CSP, CORS, CORP, COOP, and COEP against the actual immutable production origin before release |
| R-05 | Partial/corrupt cached index is treated as ready | Critical | W4 writes ready last, recovers partial downloads, re-hashes on reload, and deletes same-size corruption | Retain all-file size/SHA-256 transaction and corruption regression in W5/W6 |
| R-06 | Annotation/index contigs are incompatible and counts are zero | Critical | W4 manifest and downloaded GTF contigs are checked against versioned reference contigs for the synthetic package | Preserve check in W5 and validate every production assembly/annotation pair |
| R-07 | Paired reads and paired fragments are conflated | High | W2 proves PE fragment counting only with explicit `-p --countReadPairs` | Record `read/fragment unit` in contracts and keep flag mapping covered by integration tests |
| R-08 | Kallisto transcript TPM is presented as gene TPM | Critical | Old UI was Kallisto-only | W1 chooser/help now states the scientific boundary; enforce in manifests |
| R-09 | Exact Emscripten version cannot be reproduced | High | Archived Kallisto compiler remains unknown; all new W2 proof builds pin Emscripten 6.0.6 | Treat Kallisto binary as archived baseline and preserve W2 toolchain locks independently |
| R-10 | Archived patched vendor checkout is accidentally reset | High | Checkout is `v0.52.0-dirty`; build script can hard-reset and clean it | Preserve archive; use a separate clean checkout for rebuilds |
| R-11 | Native scientific baseline is missing | High | Native baselines now exist for all W2 engines; fresh native Kallisto 0.52.0 validation remains missing | Preserve W2 goldens; do not extend their tiny-data result into a large-data support claim |
| R-12 | GPL obligations affect Web/desktop binary distribution | High | HISAT2 and Subread are GPL-3.0; no redistribution package exists | Review corresponding-source/notices/distribution obligations before bundling or hosting modified binaries |
| R-13 | Cancel leaves persistent artifacts | High | W3 artifact and W4 multi-file download termination both recover by removing partial OPFS entries | Apply the same transaction/recovery rule to every W5 stage and test final cleanup |
| R-14 | Generated Kallisto index/output exhaust memory | Medium | Current generated index/output use in-memory Emscripten FS and returned buffers; the representative index build reached a 1,120,010,240-byte Wasm allocation high water | Preserve limitation; recommend existing indexes/smaller references; retain per-run high-water reporting without treating one run as a support threshold |
| R-15 | Existing site path is broken by a product rewrite | High | `index.html` is the published entry point and uses relative URLs | W1 keeps entry point, relative paths, static architecture, and headers |
| R-16 | fastp cleaned FASTQ or v0.23.4 duplication evaluation exhausts browser memory | High | W3 writes cleaned gzip directly to OPFS, but only tiny scientific input was used and duplication evaluation stays disabled | Keep product toggle OFF; measure representative output and define option/memory policy before W6 |
| R-17 | HISAT2/featureCounts proof success is mistaken for a viable large-file pipeline | Critical | W3 proves the storage boundary at 64 MiB and tiny engines, not human-scale feasibility | Keep product card disabled through W4/W5; require representative W6 memory/storage/runtime evidence |
| R-18 | wasm32 signed/unsigned portability changes scientific output | High | Unpatched HISAT2 TLEN was `±40` instead of native `±120`; exact signed cast restores equality | Retain PE TLEN regression and exact-match patch; expand real fixtures before W5 |
